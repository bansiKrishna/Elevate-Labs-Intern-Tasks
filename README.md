## About the Internship

This repository contains the tasks, assignments, and projects completed during my **Java Development Internship at Elevate Labs**.

The internship focuses on developing practical skills in Java programming, object-oriented programming, file handling, Spring Boot, REST APIs, CRUD operations, and software development practices using Git and GitHub.

---

## Internship Objectives

The main objectives of this internship are:

- Strengthen Java programming fundamentals
- Practice Object-Oriented Programming concepts
- Understand Java File I/O
- Build applications using Spring Boot
- Develop REST APIs
- Implement CRUD operations
- Work with Maven and project structure
- Practice Git and GitHub
- Develop clean and maintainable code
- Gain practical software development experience
